# Aero7 icon-independence VM matrix

Captured from the running Aero7 Wayland VM on 2026-09-02 after installing the
rebuilt binaries. Each application was restarted after the Plasma icon theme
changed. Application-owned artwork comes from embedded copies of the existing
AeroThemePlasma Windows 7 Aero icon pack at commit
`96950b8028a5d960cb683280fe5f1d9e33e6b8a2`.

| Application | Windows 7 Aero | Breeze | Breeze Dark | Adwaita |
| --- | --- | --- | --- | --- |
| Programs Center | `programs-center--windows-7-aero.png` | `programs-center--breeze.png` | `programs-center--breeze-dark.png` | `programs-center--adwaita.png` |
| Control Panel | `control-panel--windows-7-aero.png` | `control-panel--breeze.png` | `control-panel--breeze-dark.png` | `control-panel--adwaita.png` |
| Device Manager | `device-manager--windows-7-aero.png` | `device-manager--breeze.png` | `device-manager--breeze-dark.png` | `device-manager--adwaita.png` |
| Computer Management | `computer-management--windows-7-aero.png` | `computer-management--breeze.png` | `computer-management--breeze-dark.png` | `computer-management--adwaita.png` |

The Adwaita Device Manager capture includes its pack-backed device context
menu. The Adwaita Computer Management capture includes its pack-backed Action
menu. File/MIME and third-party program icons are deliberately outside the
Aero7 ownership boundary and may follow the selected system theme.
